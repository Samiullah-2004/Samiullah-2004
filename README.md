# 💫 About Me:
I'm Samiullah, a Frontend Web Developer and Computer Science student at NCBA&E, Lahore, currently in my 4th semester. I don't wait for graduation to build real things — I've already developed and deployed multiple live web applications using HTML, CSS, JavaScript, React.js, and Tailwind CSS.<br>I love turning ideas into clean, responsive, and functional interfaces. My projects include a live cryptocurrency price tracker powered by CoinGecko API, a real-time weather app using Open-Meteo API, and a currency exchange web app — all publicly available and fully deployed.<br>I'm deeply interested in the intersection of web development and fintech. I actively follow the crypto market on Binance and understand blockchain narratives, which gives me a unique edge when building finance-related web tools.<br>Right now I'm expanding into the MERN stack — learning Node.js and MongoDB to transition from frontend-only to full stack development. My goal is to build complete, production-ready web applications and work with international clients remotely.<br>I believe in learning by building. Every project I ship teaches me more than any tutorial ever could.<br>If you're working on something interesting in web development or fintech — let's connect.
